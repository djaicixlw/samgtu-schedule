# 🎓 Расписание СамГТУ (samgtu-schedule)

Автономное кроссплатформенное веб-приложение для студентов и старост Самарского государственного технического университета (СамГТУ).

Доступно как **Telegram Mini App (TMA)** и **Progressive Web App (PWA)** со 100% поддержкой оффлайн-режима.

---

## 🚀 Основные Возможности

1. **4-недельное цикличное расписание**:
   - Автоматический расчет текущей недели семестра по Самарскому времени (UTC+4).
   - Поддержка официальной университетской сетки звонков СамГТУ (6 пар, 08:00–19:00).
   - Жестовый горизонтальный свайпер дней с блокировкой вертикальной оси (Directional Lock).
   - Быстрый статус пары: «Идет сейчас», «Следующая», «Отменена», «Перенесена».
   - Редактирование пар для старосты: смена преподавателя, аудитории, типа занятия и прикрепление методичек 📎.

2. **Иерархический выбор учебных групп**:
   - Фильтрация по институтам / факультетам и курсам.
   - Мгновенный сквозной поиск по номеру группы.
   - Возможность ручного добавления любой группы СамГТУ и импорта расписания из ЛК.

3. **Журнал посещаемости и защита приватности (Архитектура v3 «Слепой сервер»)**:
   - **Zero-Knowledge для сервера**: Фамилии и имена студентов хранятся **исключительно локально** на устройстве старосты в зашифрованном E2EE-хранилище (AES-256-GCM + PBKDF2). Сервер СамГТУ и Cloudflare Worker не знают и не хранят ФИО студентов.
   - **Табель посещаемости (Сетка недели и Сводка семестра)**: Сетка 1..6 пар с горизонтальным листанием и сводка с **кумулятивным накопительным итогом** (Блок 1 + Блок 2) для сдачи ведомости в деканат.
   - **Анонимные слоты**: Каждому студенту генерируется уникальный 8-значный Base32 Crockford-идентификатор слота (например, `A7K2Q9X1`).
   - **Одноразовые инвайт-коды**: Староста выдает студенту одноразовый код, с помощью которого студент в один клик привязывает свой Telegram-аккаунт к своему анонимному слоту.
   - **Вкладка «Мои пропуски»**: Студент видит исключительно свои отметки и пропущенные часы (Н и УП), не имея доступа к чужим данным.
   - **Экспорт ведомости в Word**: Автоматический расчет часов и выгрузка официальной ведомости деканата в формате Microsoft Word (`.docx`).

4. **Трекер домашних заданий и Раздел «Полезное»**:
   - Ведение дедлайнов с цветовой индикацией срочности («Срок истек», «Дедлайн СЕГОДНЯ», «Осталось N дней»).
   - Раздел «Полезное»: закрепленные заметки, быстрые теги (`#лабы`, `#сессия`, `#контакты`), фильтр по предметам, вложения и ссылки.
   - Фоновая двухсторонняя облачная синхронизация между одногруппниками с защитой от перезаписи и tombstones от воскрешения удаленных заметок.

5. **Безопасность и отказоустойчивость**:
   - **100% Offline First**: Мгновенный рендер из локального кэша, стабильная работа без интернета в аудиториях и цокольных этажах.
   - **Защищенный шлюз Cloudflare Worker + KV**: Сокрытие токенов Telegram Bot API, валидация `initData` через HMAC-SHA256, fail-closed шлюз.
   - **80-битные коды старост и админа**: Защита через PBKDF2 (100 000 итераций SHA-256) и `safeEqual` (constant-time сравнение). Ограничение подбора (Rate Limit: 5 попыток / 15 минут).
   - **Бот-релей обратной связи**: Баг-репорты и тикеты шифруются через AES-256-GCM и направляются разработчику в Telegram, ответы доставляются через вебхук без публичных чатов.
   - **Диагностика и алерты**: Внутриклиентский буфер системных логов (150 событий), автоматическая дедупликация ошибок и защита от спама.

## 🛠️ Стек Технологий

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React, Sonner (Toasts)
- **Runtime**: Telegram WebApp SDK, Service Worker (PWA, Offline Cache)
- **Backend / Edge**: Cloudflare Workers, Cloudflare KV Storage, Telegram Bot API
- **Криптография**: Web Crypto API (PBKDF2 SHA-256, HMAC-SHA256, AES-256-GCM, Constant-time equality)
- **Экспорт**: `docx` (генерация ведомостей посещаемости)
- **Тестирование**: Автоматический тестовый комплекс (44 сьюта, 56 файлов тестов, 0 фиктивных заглушек, 100% честные алгоритмические и криптографические проверки)

## 💻 Локальный Запуск и Разработка

### Требования
- Node.js 18+
- npm

### Команды
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального dev-сервера
npm run dev

# 3. Запуск автоматических тестов (все 26 сьютов)
npx tsx tests/run_all.ts

# 4. Проверка типов TypeScript
npm run lint

# 5. Продакшн-сборка
npm run build

# 6. Проверка отсутствия утечек секретов в бандле
npm run check:dist
```

## 📂 База Знаний и Документация (Obsidian Vault)

Полная инженерная документация проекта оформлена в виде интерактивной базы знаний Obsidian:

- **Папка хранилища Obsidian**: `samgtu_schedule/`
  - Для открытия в Obsidian: выберите пункт **«Open folder as vault»** и укажите папку `samgtu_schedule`.
  - В ней уже настроена рабочая среда `.obsidian/` (граф связей `graph.json`, рабочее пространство `workspace.json`, горячие клавиши и плагины).
- **Структура базы знаний**:
  - `00 - Индекс и Карта (MOC)` — точка входа, MOC (Map of Content), архитектурный граф и глоссарий.
  - `01 - Архитектура и Слои` — описание слоев runtime, UI, бизнес-логики и Edge.
  - `02 - Архитектурные Решения (ADR)` — записи архитектурных решений ADR-001 ... ADR-009.
  - `03 - Модули и Компоненты` — спецификации компонентов, руководство старосты и таблица кодов групп.
  - `04 - Потоки Данных (Data Flows)` — пошаговые диаграммы синхронизации, посещаемости и ДЗ.
  - `05 - Надежность и Тестирование` — тестовые сценарии, Circuit Breaker и мониторинг.
  - `06 - Дорожная Карта и Развитие` — этапы масштабирования и бэклог.
  - `07 - Комплаенс и 152-ФЗ` — юридический и технический анализ соблюдения законодательства о персональных данных.
  - `new structure and other/` — мастер-спецификации v3 («Слепой сервер»), брифы архитекторов и политики.

Также в корне проекта поддерживаются:
- [ARCHITECTURE.md](ARCHITECTURE.md) — сводная архитектурная спецификация проекта.
- [BIG-PICTURE.md](BIG-PICTURE.md) — актуальное состояние подсистем и статус дорожной карты.
