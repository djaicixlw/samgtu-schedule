# 🎓 SamGTU Schedule

Кроссплатформенное веб-приложение расписания занятий для студентов и старост СамГТУ (Web & Telegram Mini App).

- 4-недельная цикличность расписания с автоматическим расчетом недели
- Офлайн-режим (Offline-first)
- Журнал посещаемости и учет пропусков
- Трекер домашних заданий и заметок
