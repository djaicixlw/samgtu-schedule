# 🎓 Расписание СамГТУ (samgtu-schedule)

Кроссплатформенное автономное веб-приложение для студентов и старост Самарского государственного технического университета (СамГТУ).

Доступно как **Telegram Mini App (TMA)**, **Progressive Web App (PWA)** и нативный **Android APK (Capacitor)**.

---

## 🚀 Основные Возможности

1. **4-недельное цикличное расписание**:
   - Автоматический расчет текущей недели семестра по Самарскому времени (UTC+4).
   - Поддержка фиксированной сетки звонков СамГТУ (7 пар).
   - Жестовый горизонтальный свайпер дней с блокировкой вертикальной оси (Directional Lock).
   - Быстрый статус пары: «Идет сейчас», «Следующая», «Отменена», «Перенесена».

2. **Иерархический выбор учебных групп**:
   - Фильтрация по институтам / факультетам и курсам.
   - Мгновенный сквозной поиск по номеру группы.
   - Возможность ручного добавления любой группы СамГТУ и импорта расписания из ЛК.

3. **Журнал посещаемости для старост**:
   - Учет отсутствующих и уважительных причин (2Н / 2УП).
   - Автоматический расчет академических часов с разделением по блокам семестра.
   - Формирование официальной ведомости деканата в формате Microsoft Word (`.docx`).
   - 4-уровневый каскад скачивания отчетов в Telegram Mini App на Android и iOS без утечек персональных данных.

4. **Трекер домашних заданий**:
   - Ведение дедлайнов с цветовой индикацией срочности («Срок истек», «Дедлайн СЕГОДНЯ», «Осталось N дней»).
   - Прикрепление ссылок и материалов.
   - Фоновая двухсторонняя облачная синхронизация между одногруппниками с защитой от коллизий.

5. **Безопасность и архитектура**:
   - **100% Offline First**: мгновенный рендер из локального хранилища, работа без интернета в аудиториях.
   - **Защищенный шлюз Cloudflare Worker**: сокрытие токенов Telegram Bot API и ключей хранилища.
   - **Криптографическая авторизация**: проверка PIN-кодов старост и админа через SHA-256 (Web Crypto API).
   - **Диагностика и алерты**: внутриклиентский буфер логов, отправка баг-репортов со скриншотами и автоматическая дедупликация краш-репортов.

---

## 🛠️ Стек Технологий

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React, Sonner (Toasts)
- **Runtime**: Telegram WebApp SDK, Capacitor (Android), Service Worker (PWA)
- **Backend / Edge**: Cloudflare Workers, Cloudflare KV Storage, Telegram Bot API
- **Экспорт**: `docx` (генерация ведомостей посещаемости)
- **Тестирование**: TypeScript / Node.js автоматический тестовый комплекс (23 сьюта)

## 💻 Локальный Запуск и Разработка

### Требования
- Node.js 18+
- npm

### Установка и запуск
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального dev-сервера
npm run dev

# 3. Запуск автоматических тестов
npx tsx tests/run_all.ts

# 4. Проверка типов TypeScript
npm run lint

# 5. Продакшн-сборка
npm run build
```
